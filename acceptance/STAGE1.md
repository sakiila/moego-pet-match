# 阶段 1 验收记录：本地试玩闭环

日期：2026-10-22

> 历史验收记录：本页保留规则版本 1 当时的测试结果、截图与示例分数，不代表当前规则。现行规则版本 5 为每格 100 分、催单及猜主人奖励 1000 分；直线五连生成吹风机，双剪刀先合成、再次相邻交换才发动清盘。当前口径见 [V1_RULES](../V1_RULES.md) 与 [GAME_FLOW](../GAME_FLOW.md)，后续已执行验证见 [design-qa](../design-qa.md)。

范围：`web/` 中「开局准备 → 90 秒棋盘 → 基础报告 → 再开一局」，占位宠物，本地运行。
状态：功能已实现，自动化测试与浏览器验证见下文；文档未覆盖的 4 点已确认；尚未经过真人试玩与真机触控验证。

## 如何复现

```sh
cd web && npm install && npm test && npm run typecheck && npm run build
npm run dev   # http://localhost:5180 ，陈列页 /dev/gallery
```

开发环境专用 URL 参数（生产构建会忽略）：

| 参数 | 作用 |
| --- | --- |
| `?seed=11` | 固定随机种子 |
| `?speed=0.25` | 游戏时钟倍速（慢放便于观察，快进便于走完整局） |
| `?t0=85000` | 从指定游戏毫秒开始（直接验证催单、最后 10 秒、到时收尾） |
| `?preset=cascade` | 拖 (4,4)→(4,3)：三消 → 三消 → 四消 = 210 分并留下横梳 |
| `?preset=tools` | 横梳与剪刀相邻（梳＋剪合体）＋一个竖梳 |
| `?preset=shuffle` | 拖 (1,2)↑(0,2) 后成死局，触发系统洗牌 |

预设棋盘定义在 [web/src/dev/presets.ts](../web/src/dev/presets.ts)，并有测试保证其效果。

截图均在浏览器 390×844 视口下拍摄（陈列页除外），存于 [stage1/](stage1/)。浏览器面板在后台时渲染帧会停住，部分截图拍到了过渡动画的中间帧（半透明、棋子在途），不代表最终画面。

## 与已确认图稿的差异

### mobile-prep-v1（开局准备）

1. 宠物用 emoji 占位，不是正式 B 类贴纸（阶段 1 计划如此；阶段 3 接入真实素材）。
2. 顶部没有「回门店」：阶段 1 还没有门店页。
3. 没有「{petName} 也来啦！」：阶段 1 没有身份，无法判断自家宠物。
4. 规则卡用 emoji 图标，图稿是两只小猫的交换示意插画。
5. MoeGo 为文字字标，不是品牌 Logo 图形；标题没有装饰笔触，阵容卡顶部没有挂扣装饰。
6. 阵容卡内的头像多了一层白框（PetTile 自带底色框），图稿是贴纸直接放在底色上。
7. 字体使用系统圆体，图稿为更粗的圆润展示字体。

### mobile-board-v3（棋盘，催单中）

1. 棋子为 emoji 占位；工具为简化 SVG（梳子＋↔／↕ 角标、剪刀＋十字角标），图稿是更精细的插画工具。
2. 工具预览用淡色虚线格标出直接范围，图稿是整行发光高亮。
3. 催单条没有顶部挂扣装饰，火焰与时钟为 emoji／简化图标。
4. 催单未出现时，催单位置保留空白（为了不推动棋盘），因此开局前 30 秒状态区与棋盘之间有一段留白；图稿只画了催单进行中。
5. 底部设置／退出使用 emoji 与箭头，图稿为线性图标。
6. 设置弹层只有语言切换；音乐、音效、轻震开关尚未实现（不在本目标范围）。
7. 字体同上。

## 文档未覆盖的问题与确认结果

实现中发现以下 4 点文档没有写清。初版先按暂定方案实现，随后逐条向用户确认（2026-10-23），四条均确认采用当前实现，并已写回文档：

| # | 问题 | 确认结果 | 写回位置 |
| --- | --- | --- | --- |
| 1 | 被扫到或发动的道具格本身算不算分、服务格数与催单进度 | 全部计入：覆盖范围内每格（含道具本体）计 10 分、计入服务格数与催单进度；宠物服务次数只计宠物格 | GAME_FLOW 计分表「基础分」、V1_RULES「基础计分」 |
| 2 | 「工具发动次数」中一次合体算几次 | 按用掉的道具个数，合体计 2 次 | V1_RULES「工具发动次数」 |
| 3 | 图稿有、UI_COPY 未收录的棋盘页文案 | 中文用图稿原文，英文按暂拟版本，补进 UI_COPY 第 4 节 | UI_COPY 第 4 节 `board.title` 等 7 个 Key |
| 4 | 阶段 1 没有门店，提前收工后去哪里 | 回到新一局的开局准备页；接入门店后改为回门店 | 本记录（阶段性安排） |

以下为体验参数，按文档「试玩调节」处理，未作为规则：拖拽触发距离（0.45 格）、洗牌演示时长（700 ms，期间两个时钟暂停）、带教贴纸显示 4 秒、催单成功／未赶上提示停留 1.5 秒、提示区优先级（收尾 > 洗牌 > 带教 > 卡关提示 > 最后 10 秒）。
