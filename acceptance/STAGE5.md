# 阶段 5 验收记录：完整首版与部署

## 声音与轻震（2026-10-23）

- **规则**：音乐、音效首次关闭；设备支持震动时轻震首次开启；三项各自记住，开局或重开设置不重置。背景音乐只在棋盘计时期间播放，局终收尾音后停止，其他页面保持安静（2026-10-23 确认，写入 UI_COPY 第 10 节）。
- **音效与触感**（`web/src/game/feedback.ts`，纯函数）：普通消除「啵」并随连锁批序逐级上扬；梳子「刷」、剪刀「咔嚓」；合体只出一个主音；普通批次一次短点，合体与第 3 批以后的连锁短双点；同一时刻多个批次限频只放一次。在 `useGameSession` 中按游戏时钟、每个批次到结算时刻（与加分飘字同时）放一次；局终放收尾音。
- **声音来源**：`web/src/audio/sound.ts` 用 WebAudio 现场合成全部音效与一段低音量五声音阶循环作背景音乐占位，没有音频文件；在第一次用户操作时解除浏览器自动播放限制；没有 WebAudio 时静默。
- **后台**：页面隐藏时停止音乐、暂停声音、取消震动；回来后按开关恢复（音乐只在棋盘上恢复）。
- **设置**（对照 mobile-settings-v1）：底部抽屉，门店版为语言 + 背景音乐 / 消除音效 / 轻震 + 「会记住你的选择。」（[门店](stage5/sound-01-shop-first.jpg)）；棋盘版只有三个开关，打开时计时继续（[棋盘](stage5/sound-03-board-settings.jpg)）。不支持震动时轻震开关不可用并显示「此设备暂不支持轻震，可正常游玩。」。新增 Toggle 组件（开 / 关文字 + 圆点位置），陈列页列出首次、全开、轻震不可用、棋盘版。
- **测试**：9 个（`web/src/game/__tests__/feedback.test.ts`）：各种批次的音效与震动模式、连锁音调上扬、限频；偏好首次默认、读写往返、存储损坏回到默认、不支持震动时轻震按关。
- **浏览器走查**（390 × 844，用记录器替代真实声音与震动）：首次设置为音乐关、音效关、轻震开；打开音效和音乐后刷新仍保持；门店页面不播放音乐；固定棋盘梳＋剪合体只出一次合体音和一个双点 `[16,60,22]`；三消 → 三消 → 四消的 210 分连锁依次为「啵」级别 0、1、2，震动短点、短点、双点；无效交换不出声不震；切到后台停止音乐并取消震动，回来后音乐恢复；局终收尾音。

## 生产运行准备（Docker，2026-10-23）

- **一个服务提供全部**：生产时由 `STATIC_DIR` 指定前端构建目录，同一服务提供页面、API 与图片；带哈希的 `/assets` 长期缓存、`index.html` 不缓存，其他页面路径回退到 `index.html`，`/api`、`/img`、`/assets` 的 404 不返回页面。新增 `GET /api/health`（含数据库检查，2 秒超时，不通返回 503）。新增 `HOST`、`DATABASE_SSL=disable`（只用于本机验证）两个可选变量。测试 7 个（`server/__tests__/static.test.ts`）。
- **打包**：服务端用 esbuild 打成一个 `server.mjs`（含 `web/src/engine` 等源码），npm 依赖外部安装。
- **镜像**（根目录 `Dockerfile`）：前端构建 → 服务端打包 → `node:22-slim` 运行层只装生产依赖，以 `node` 用户运行，带 HEALTHCHECK。`.dockerignore` 只放入 `web/` 与 `server/` 源码。
- **部署文件**（`deploy/`）：`compose.yml`（只映射 `127.0.0.1:8787`、图片缓存卷、日志轮转、自动重启）、`production.env.example`（只列服务运行需要的变量）、`DEPLOY.md`（构建、送达、启动、反向代理要点、更新回滚、上线前待办）。
- **本机验证**：
  - 本机架构镜像 464 MB，容器内以 uid 1000（node）运行，`/app` 下只有 `server.mjs`、`public/`、依赖与 `package.json`，没有 `.env`。
  - 容器连本地开发库与本地目录存储：健康检查 healthy；Playwright 390 × 844 走通选身份 → 门店 → 完整 90 秒一局（真实拖动）→ 报告「已保存」→ 上传照片（文件落到挂载目录、记录写入）→ 图鉴 → 排行榜，无 5xx、无页面错误。
  - 生产构建里没有调试接口与陈列页（`window.__petMatch`、`__feedbackLog` 均不存在，`/dev/gallery` 只返回应用外壳）。
  - `linux/amd64` 镜像构建成功（约 1.5 分钟），在模拟下 `sharp` 正常加载。
