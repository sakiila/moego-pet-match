## 构图

头部下缘到下巴为止，不带脖子、胸口、爪子、背带、项圈、蝴蝶结或其他服饰。耳朵、胡须与吐出的舌头要完整；长垂耳即使低于下巴，也保留耳朵本身，不把耳朵误裁成颈部。

使用透明背景和清楚的白色贴纸描边。导出时统一头部占比与透明留白，页面只做等比展示；不能通过裁掉耳朵、胡须或下巴来凑大小。

## 辨识度

保留原宠物的毛色、花纹、耳形、表情与头部姿态，尤其是眨眼、吐舌、歪头等个人特征。统一插画质感，不把不同宠物画成通用的猫脸或狗脸。

首批素材：Deedee / Emma，Maodu / Bob，Boluo / Bob，Momo / Yoo，Marley / Rachel Shaw，Koa / Sam Pineda。每只同时检查大图和实际 48 px 小图；缩小后仍应能看清表情，并区分各自的毛色与轮廓。

## 文件与验收

原照片、素材关联记录和审核文件保持原样。样张另存为新的透明 PNG；历史样张不覆盖，页面只做 CSS 展示，不重绘或拼接 PNG。
