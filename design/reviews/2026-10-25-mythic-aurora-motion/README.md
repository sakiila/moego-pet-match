## 实现与验证计划

- 在 Icon 内对原 PNG 叠加透明轮廓遮罩下的流光与星芒；6 秒循环，22px 头像仅轻闪。复用原图，不生成或替换徽章。
- 称号列表的镇店之宝标签游彩并掠过高光；锁定状态和减少动态效果保持静态。
- 隐藏称号的名称、条件和读屏文字按当前查看者的解锁状态显示；未读取或读取失败时使用已有隐藏文案。保留他人已获得徽章的图案。
- 先写解锁/隐藏边界的组件回归测试，确认失败，再实现；验证中英文列表、头像、名片提示、佩戴交互、减少动态效果与真实图鉴计数。
- 运行前后端相应测试、类型检查与构建；查看实际浏览器动效并与选定稿对照。完成后按改动主题分别提交，一起推送 main，跟进自动部署与线上版本。


## 验收 · 2026-10-26

- 原稿与实现同次查看：选定的 1536 × 1024 动效分镜，对照实际 390 × 844 中文称号列表的掠光、星芒关键帧。沿用原 56px 列表徽章与布局；没有把分镜里的放大主图、示意头像或额外光点作为产品素材。
- 浏览器实际动画：徽章的三层流光/星芒、标签的游彩/掠光均为 6000ms；首页头像实测 22px，仅一条轻闪动画。原 PNG 未改。
- 中文 390px、英文 320px 列表均无横向溢出；佩戴传奇再切回镇店之宝，选中状态与按钮禁用状态正确。
- 未解锁称号行真实动画数量为 0，名称和条件均隐藏；在浏览器中临时将现有 prefers-reduced-motion CSS 分支激活后，已解锁行真实动画数量为 0、光效层 display:none。没有改用户系统的减少动态效果设置；未做真机系统设置切换。
- 名片陈列页中英文未解锁/已解锁分支、称号签与轻点条件提示通过。另以本地未解锁测试身份经过登录 → 总榜 → 他人名片，名称与读屏文字保持 Hidden Title，条件为喵喵喵；验证后恢复原身份与中文。
