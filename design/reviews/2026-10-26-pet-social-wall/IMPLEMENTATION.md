# 毛孩子动态 · 实施阶段

用户于 2026-10-26 确认当前设计方向并要求继续。按仓库分阶段约定，先完成独立的社交前端模块与交互预览，再接真实身份、持久化 API 和 Slack 导入。

## 本阶段（已完成前端交互预览）

- 在现有 React / Vite 项目里实现设计稿，不新建另一套应用或修改游戏规则。
- 8 个页面的核心操作可用：进入预览、浏览、照片放大、发布、表情、文字回复、消息、删除/隐藏。
- 演示模式明确标识；数据仅保存在当前浏览器。演示验证不冒充真实 Slack 登录。
- 新图标按项目约定用原生 SVG 编写并统一经 Icon 使用，不从整页截图提取。
- 页面只组合组件，新增样式使用 tokens；组件加入陈列页，覆盖中英文、长姓名、空、加载、错误等状态。
- 生产入口保持未开放；预览不调用游戏或 Slack API，不采集频道内容。
- 本地校验类型、构建、关键状态规则；在浏览器 390×844 下走完整交互并与已选稿比较。

## 后续真实接入

- Slack OpenID 身份、服务器会话、内容与图片鉴权。
- 帖子、媒体、表情、评论、消息与删除/隐藏持久化 API。
- Slack 事件可靠接收与幂等处理、限定频道、补历史、原帖修改删除、图片授权下载。
- 单向导入；不导入 Slack 互动，不写回 Slack，不做视频。
- 正式启用前配置 Slack App 登录与读取权限、成员告知与不被同步入口。

本阶段不推送、不部署，也不开启频道监控。

类型检查、前端 353 项单测（含新增 9 项社交规则）及 8 项版号检查、构建均通过。浏览器已验证 390×844 与 1280×720 的主要交互，完整报告为仓库根目录 design-qa.md 的“毛孩子动态”章节；截图位于 /tmp/moego-social-qa/。
