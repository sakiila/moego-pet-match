# 独立素材样式偏差修正记录

2026-10-23。用户反馈「不对，你这个素材和之前讨论的样式不一致」。此前 `home-entry-original-v1` 与 `library-original-v1` 手工 SVG 重绘改变了曲线、比例和材质层次，整套标记为 `rejected_style_mismatch`；技术校验通过不代表视觉还原通过。旧包保留为退回稿。

`experiments/` 为未选用的修正试验：包括 ImageGen 提示词及自动矢量追踪测试。生成复现仍会改变高光或造型，追踪测试也未达到素材质量要求，因此均未用于正式交付。

随后用户明确选择「按原图拆分透明 PNG（推荐）」，允许本次通过本地拆分与去底，保留原有样式，不重绘。当前交付唯一入口为 [原稿 PNG v2](../../../assets/icons/library-original-png-v2/README.md)，包含 47 枚主图标与原稿内 2 枚白色版本。原始已确认图稿未改，未修改游戏代码。
