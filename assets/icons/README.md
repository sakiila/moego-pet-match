## 独立图标制作

用户退回前一套手工 SVG 重绘，并明确选择「按原图拆分透明 PNG（推荐）」。当前交付统一为[原稿 PNG v2](library-original-png-v2/README.md)：49 枚原尺寸透明母版（47 主图标＋2 白色版），另有 32／40／48／512 px 尺寸导出 196 份。[逐枚原稿对照](library-original-png-v2/preview.html)、[全套总览](library-original-png-v2/overview.png)、[完整包](library-original-png-v2/moego-original-png-v2.zip)及[来源校验](library-original-png-v2/manifest.json)已提供。

本次只拆分与去底，保留原稿轮廓、比例、配色与明暗；主体不透明像素 RGB 与来源一致。白色材质、镂空及浅投影单独处理，不再重新设计或用几何 SVG 替代。用户授权针对本次素材整理，不自动授权接入游戏；本轮未改游戏代码。

`home-entry-original-v1` 与 `library-original-v1` 均为样式未通过的旧 SVG 重绘稿，保留作过程留档，不作为当前素材交付。
