## 文件与尺寸

- `svg/<group>/<id>.svg`：独立矢量文件，无位图、外部依赖或背景底图。
- `png/<size>/<group>/<id>.png`：32／40／48／512 px 透明导出，每枚四份。
- `sprite.svg`：包含全部 59 个 `<symbol>`，symbol ID 与素材 ID 一致。
- `overview.svg`／`overview.png`：用于审阅的整套总览，卡片底色不是素材的一部分。
- `reference/`：十张已确认原稿的未修改副本。
- `src/`、`build.mjs`、`preview.template.html`：原生构建源与预览模板。
- `manifest.json`：语义、模式、能力、尺寸、推荐最小尺寸、透明边界与 SHA-256。
- `palette.json`：独立素材共用配色。

一般图标使用 256 × 256 viewBox；称号空框使用 400 × 192，保持长条比例。PNG 的尺寸目录表示宽度，称号框的高度按比例导出，例如 512 × 246；不要将其强行拉伸为正方形。长条称号框建议至少 160 px 宽，图鉴空态建议 64–96 px；32／40／48 px 文件仍完整提供。

## 使用约定

普通与鱼关工具沿用相同能力：梳子／海螺为横扫或竖扫，剪刀／贝壳为十字；吹风机和大浪花仅全盘合体演出，不成为独立棋子。六枚常规道具提供固定橙色角标版，也可组合 `-base` 主体与 `ability-h`／`ability-v`／`ability-plus`；能力轴线不随主体姿态旋转。

新纪录旗仅保留真实旗面外轮廓与投影，没有多余回折线或浅色折面。称号框保留左侧角花，没有圆戳；文字保持动态，文本安全区见清单。名次徽记的数字是实际名次，不按列表下标重排；同分 1、2、2、4 的两个第 2 名共用 `rank-2`。排行榜 4 及以后为界面动态文字，不生成固定数字图标。

设置图标表达类别，开／关及设备不可用仍由现有文字和开关状态表达。上传收件反馈可复用勾印记，但原有「已收到、后续人工处理」文案不能被替换为已上架。宠物、单鱼、真实照片与品牌插画继续使用既有内容素材，此库没有重新生成它们。

白色变体：`open-shop-white`、`share-image-white`、`save-image-white`；用于深色或橙色实底。所有 SVG 字母和名次数字均为路径，不依赖字体。称号、计时、得分与玩家信息不烘焙进图标。

SVG Sprite 用法示例：

```html
<svg viewBox="0 0 256 256" width="48" height="48" role="img" aria-label="重试">
  <use href="sprite.svg#retry"></use>
</svg>
```

正式页面仍遵守项目组件、props、i18n、tokens 和陈列页约定；此处没有新增 React 图标组件或替换现有 UI。

## 构建与验证

已有 `sharp` 时运行 `node build.mjs`；可用 `ICON_SHARP_MODULE` 指向已有模块路径。无需图片 API，PNG 直接从同一 SVG 渲染。解压后的包包含原生源和原稿副本，可独立重建。

构建时核对每张 PNG 的可见像素、透明像素和画布边缘；236 张全部保留透明通道，四条边缘均无可见像素；3 枚白色变体的可见像素全部为白色。检查全部独立 SVG 的 XML、外部引用、导出哈希和 Sprite 引用。浏览器预览支持尺寸、PNG／SVG、浅色棋盘／深色／橙色背景和十批原稿对照；具体运行记录见 [validation.json](validation.json)。本轮未运行游戏测试或接入回归。
