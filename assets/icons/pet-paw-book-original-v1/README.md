# 宠物爪印簿 · 原稿组件提取

2026-10-26 用户提供三状态设计稿，明确要求“做元素组件裁切，不要手绘，然后修改代码”。本批直接使用附件像素，不重新生成、不描摹或重绘；替换此前 `PawGlyph.tsx` 的五个 SVG 图形，并补齐这张稿中的其余控件图标。

- `source.png`：用户附件的逐字节副本，不替换已留档的概念稿。
- `source-crops/`：每个图形未经去底的原始矩形区域。
- `extract.py`：可复现的裁切、透明蒙版与抗锯齿边缘去底程序。
- `extraction.json`：来源 SHA256、图稿尺寸、原图坐标、母版尺寸、每枚母版 SHA256 和原 RGB 保留像素数。
- `validation.json`：11 枚母版、12 份导出、3,050 个不透明像素 RGB 保留、无放大及旧图标文件未变的实际校验结果。
- `preview.png`：白底与深色底的透明边缘检查图；上方为最近邻放大三倍，下方为原生尺寸，不作为页面素材。
- 本版透明母版已留档在 `masters/`。用户后续选择“宠物小动作”第 2 稿，当前图标库 `masters/18-pet-paw-book/` 已改用该稿的高清提取，见 `../pet-paw-icons-playful-original-v1/`。

只调整透明度和抗锯齿边缘的背景混合；最终 alpha=255 的像素 RGB 均与源图对应像素完全相同，脚本逐枚断言。猫脸内的白色、球内的浅色和选中勾的白色保留；空心爪印、爱心与箭头的背景透明。小于 8/255 的透明噪点清除。

母版保持原稿分辨率，导出只做等比缩小与透明画布居中，不放大或锐化。箭头保留原始长宽比。按钮、底色、纸张、文字、数字、头像和布局仍为组件；宠物与原有开发者章复用正式素材，没有从本图重新截取。

使用已安装 Pillow、NumPy 的 Python 复现：

```sh
python3 assets/icons/pet-paw-book-original-v1/extract.py
```

本命令只复现历史母版，不覆盖当前图标库。当前页面导出遵循新选定稿的提取与导出命令。
