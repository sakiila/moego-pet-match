每枚提供 `svg/<name>.svg` 与 `png/<name>.png`（512 × 512）。实际小尺寸 PNG 位于 `png/32/`、`png/40/`、`png/48/`。SVG 统一使用 `0 0 256 256` viewBox，均无背景矩形；PNG 保留真实透明通道。

[打开尺寸与背景预览](preview.html)。预览的大图使用导出的透明 PNG，小尺寸行直接使用 32／40／48 px PNG，深色背景行使用 SVG；另展示橙底白爪。可展开已确认原稿对照造型；原稿副本仅用于审阅，不是正式图标。

图标由原生 SVG 路径构建，PNG 从同一 SVG 渲染导出。保留炭黑描边、橙白主色、轻量渐变，以及书页／封皮、杯柄／底座和猫狗前后层次。未裁切效果图、嵌入位图、恢复旧高光素材或修改游戏组件。源图中的纹理与生成噪点未复制，当前独立稿的几何与小尺寸表现需要单独审阅。

文件与哈希记录见 [manifest.json](manifest.json)，配色来源为 [palette.json](palette.json)。`build.mjs` 是此批独立素材的生成源；已有 `sharp` 时可运行 `node build.mjs`。也可通过 `ICON_SHARP_MODULE` 指向本机已有的 sharp 模块，无需调用图片 API。
