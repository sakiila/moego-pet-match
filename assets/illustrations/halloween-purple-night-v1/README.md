## 店面显示契约

裁切框为首页原稿 `x=24,y=374,width=800,height=570`，保持 800∶570 等比；不能单独拉伸宽高。

- 暖色窗口底：建议局部矩形 `[105,115,600,343]`，即 left 13.125%、top 20.175%、width 75%、height 60.175%，在插画 frame 下层，用主题令牌绘制。
- 宠物实际显示区：`[127,137,556,321]`，即 left 15.875%、top 24.035%、width 69.5%、height 56.316%。这只是可用区，不把固定宠物画在图片里。
- 参考气泡覆盖区：`[450,133,262,151]`，即 left 56.25%、top 23.333%、width 32.75%、height 26.491%。
- 参考名牌覆盖区：`[584,394,175,84]`，即 left 73%、top 69.123%、width 21.875%、height 14.737%。

原稿中的气泡与姓名牌遮住了部分右立柱和柜台上沿，因此那里没有可恢复的源像素。本包保留透明缺口，没有补画或复制拼接立柱；正式气泡与名牌需要覆盖上述位置。更长的名字可以让实时名牌向左扩展，不能缩字或将文字烘焙回图片。

### 手机报告单行派生

用户选定的报告稿为一行标题，原正式字标为两行，因此补充 `grooming-report-card-inline.webp`（1837×195，92,792 bytes）。原两行文件仍保留。新稿将原浅色字标的 `Grooming`、`Report Card` 与两侧原强调线分离，在同高透明画布上居中重排，没有重画、缩放或重采样；143,990 个原非透明像素各保留一次。

| 左强调线 | `[0,61,92,238]` | `[4,9]` |

原两行字形的低 alpha 抗锯齿边缘互相接近，不能只按一条水平线裁开。脚本先用 alpha>20 的独立连通区域区分两行与强调线，再把标签传播至低 alpha 边缘，保留全部原 RGBA。输出以无损 WebP 编码，并验证最终解码 RGBA 与组成画布逐像素相同。紫底预览为 `previews/grooming-report-card-inline-plum.png`；手机 340px 宽显示时约 36.1px 高。
