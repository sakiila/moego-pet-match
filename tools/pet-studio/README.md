# MoeGo 宠物素材工作台

在本机浏览器中挑选照片、调整裁切、移除背景并导出透明 PNG。它是独立的素材制作工具，游戏玩法与上架流程仍按项目原有方案推进。

## 启动

在访达中双击本目录的 **`启动工作台.command`**，或在本目录的终端运行：

```sh
./run.sh
```

准备完成后，在浏览器打开 **http://127.0.0.1:8765**。保留启动终端；停止服务时按 `Ctrl+C`，下次使用时重新启动即可。

首次启动会创建工具专用的 Python 环境、安装依赖、构建界面，并从官方发布地址下载约 **168 MiB** 的 U2Net 抠图模型，需要联网和一些等待时间。需要 Python 3.11–3.13、Node.js 20.19+（含 npm）。后续启动复用已准备好的环境和模型。

## 制作一张素材

1. 从左侧素材库选择照片，或点击「上传照片」导入 JPEG、PNG、WebP 静态照片；单张不超过 25 MB、4000 万像素。
2. 点击「调整裁切」，将目标宠物完整留在框内，特别注意耳朵、毛发和尾巴。
3. 选择风格，并调整主体大小、白描边和柔和阴影：
   - **真实抠图（natural）**：保留原照片质感。
   - **MoeGo 贴纸（sticker）**：在透明主体外增加白色描边。
   - **轻插画（soft）**：使用本地柔和色彩滤镜，保留真实花纹；不进行 AI 重绘。
4. 点击「一键抠图并生成」，等待本机处理完成，再通过「原图 / 处理结果 / 对比」检查效果。
5. 选择 **512 或 1024** 尺寸，点击「导出透明 PNG」。仅切换导出尺寸可复用已有结果；更改裁切或视觉参数后，重新生成再导出。

当前素材库包含 **105 个照片区域**，其中有同一张照片拆出的多个区域、同一宠物的重复照片以及待确认身份；105 不是已核实的独立宠物数量。JoJo 的聊天身份确认单独读取并应用，生成素材不会连带确认照片可用性或完成上架审核。

## 保存与备份

裁切和风格参数会自动保存。顶部显示 **「已保存到本机」**，表示服务端已确认写入磁盘；「有修改待保存」「尚未保存」和浏览器草稿不等于完成保存。多窗口修改同一照片时会提示版本冲突，确认要保留的修改后再保存。

默认工作目录为项目根目录的 `data/pet-studio/`：

| 路径 | 保存内容 |
| --- | --- |
| `studio.sqlite3` | 每个区域的设置、参数版本、当前所选照片与任务记录 |
| `uploads/` | 本地上传的原始照片 |
| `results/<任务 ID>/image.png` | 本次参数版本生成的透明成品 |
| `results/<任务 ID>/cutout.png` | 本次处理的透明主体图 |
| `thumbnails/` | 预览缩略图缓存 |
| `models/u2net.onnx` | 本地抠图模型 |

每次生成保留当次参数快照，并写入独立任务目录，后续生成不会覆盖旧结果。刷新页面或重启服务后，可继续读取已保存的设置与结果；被中断的任务需要重新生成。浏览器未提交的草稿仅属于当前浏览器。

**备份时先停止服务，再复制整个 `data/pet-studio/` 文件夹**，不要只复制数据库文件；运行中的 SQLite 可能还有配套的 WAL 文件。已有素材库仍依赖项目中的 `data/pet-materials/`，迁移到另一台电脑时也需保留该来源目录。

工作台只读取既有 `data/pet-materials/` 原图、人工核对 Excel、审核索引和 `user-confirmations.jsonl`，不会改写它们，也不会恢复旧 Excel 标注。

## 处理范围与验证

照片通过本机回环地址交给本地 CPU 模型处理，使用过程不调用云端图像 API、不上传照片。首次安装所需的依赖和模型下载属于运行环境准备。

复杂毛发、透明物体、遮挡或多只宠物重叠时，自动抠图可能保留多余主体或丢失细节；先调整裁切并重新生成，再检查透明边缘。目前没有画笔蒙版编辑器或批量审批功能，身份与素材质量仍需人工判断。

已通过 **13 项后端 / API 自动化测试**，并完成真实 U2Net 模型在浏览器中的生成与透明 PNG 下载验证。已检查 390 × 844 手机布局，无横向溢出、操作控件可见；512 导出文件确认为 512 × 512 RGBA，透明度覆盖 0–255。测试命令（在项目根目录运行）：

```sh
tools/pet-studio/.venv/bin/python -m pytest tools/pet-studio/backend/tests tools/pet-studio/tests -q
```
